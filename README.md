# صدقة جارية | Sadaqa Jariya

صفحة ويب بسيطة: مشغّل قرآن (114 سورة، 5 قرّاء)، أدعية للمتوفين وأدعية عامة بزر نسخ، وسبحة إلكترونية تحفظ العدّ. مهداة صدقة جارية على روح ضحايا الطريق الدائري.

A single-file web page: a Quran audio player (all 114 surahs, 5 reciters), duas with copy buttons, and a persistent digital tasbih counter.

**Live:** https://sadaqa-jariya.surge.sh

## Tech
HTML, CSS and vanilla JavaScript in one `index.html`. No build step, no dependencies. Audio streams from public recitation servers.

## Run
Open `index.html` in any browser.
